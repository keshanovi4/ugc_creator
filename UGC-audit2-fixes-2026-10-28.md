# SNEG — исправления повторного аудита

Исправлены REV-01…REV-12 из [повторного аудита](UGC-audit2-2026-10-28.md) и дополнительные сценарии очереди, квоты, очистки и Telegram. Исходные диагностические JSON сохранены как история состояния до исправлений.

| Пункт | Результат |
| --- | --- |
| REV-01 | Обязательная версия для изменения, публикации, отмены и сверки поста. Каждый переход увеличивает версию. Подтверждение показывает точный текст и аккаунт; смена аккаунта, переданного интерфейсом, отклоняется. |
| REV-02 | Оценка привязана к критериям и конфигурации. Ответ на уточнение и возврат из резерва пересчитывают правила и убирают устаревший ИИ из отбора. |
| REV-03 | Редактор хранит исходную версию. При конфликте черновик сохраняется, отправка блокируется, перенос собственных правок требует отдельного действия. |
| REV-04 | Режим правил явно перекрывает настройки провайдера из окружения. Предыдущий ИИ архивируется, ответы отключённого/заменённого провайдера не применяются. |
| REV-05 | Telegram предлагает свои и свободные анкеты, закрепляет их атомарно, показывает ответственного. Отзыв роли снимает назначения. Чужие карточки открываются без решений. |
| REV-06 | Ошибка вопроса сохраняет ввод. Конфликт сохраняет текст; /send повторно подтверждает отправку. Очистка — после успеха, /cancel или истечения срока. |
| REV-07 | Отзыв выбранной анкеты создаёт адресное уведомление ответственному и автору решения, без повторного события при повторе запроса. |
| REV-08 | Единый запрос для поиска, обновления и пагинации. Назначение сохраняется при глобальном поиске; активные фильтры видны и сбрасываются отдельно. |
| REV-09 | Отдельный черновик заметки; обновление сохраняет открытые секции, фокус, положение курсора и прокрутку. |
| REV-10 | Явные режимы нового поста и редактирования, отдельный сброс, предупреждение о несохранённых правках, правильные кнопки сохранения. |
| REV-11 | Для Telegram, ИИ, Threads и обслуживания видны последняя попытка, успешный проход, активная ошибка и история восстановления. |
| REV-12 | Вторичный текст затемнён; проверен контраст ≥4,5 на бумажном, светлом и тонированном фоне. |

Дополнительно:

- Telegram получает кандидатов по всей доступной очереди; проверен переход за позицию 500.
- Callback подтверждается до редактирования Telegram-сообщения.
- Квота ИИ отображается отдельным состоянием с временем повтора; ручной отбор доступен.
- Очистка старой кампании сохраняет сообщения и операции другой активной анкеты того же пользователя.
- UGC и охваты имеют отдельные итоги ИИ. Общий приоритет сохраняет рекомендацию, если подходит хотя бы одно направление.
- Мобильная шапка и фильтры сокращены: три полные заявки в окне 390×844, основные кнопки остаются крупными.
- Диалоги получили доступные имена, фокус клавиатуры учитывает раскрытые секции. Язык документа и кандидатские ошибки/подтверждения переключаются вместе с интерфейсом.
- Журнал команды показывает автора изменения доступа. Ошибки обработчиков объяснены обычным текстом.

## Проверка

- `npm test`: **88/88**, включая 15 новых регрессионных сценариев. Все внешние сообщения и публикации в тестах подменены; SQLite в памяти, кроме изолированных проверок копий.
- `npm run build`: синтаксис 26 модулей и обязательные ресурсы проверены.
- Браузер: «Мои» + поиск даёт одинаковые нулевые результаты до/после обновления; заметка остаётся раскрытой с текстом и фокусом после фонового изменения; конфликт двух окон сохраняет имя из черновика и город из актуальной версии; объединённая анкета успешно сохранена; переключение на казахский проверено; редактор поста явно меняет режим и сбрасывает ID нового поста.
- Мобильный снимок: `sneg-ugc/screenshots/audit2-fixed-mobile.png` (локально, вымышленные данные).
- Регрессионный запуск: `node tools/audit2-probes-2026-10-28.mjs`. Теперь он проверяет исправления, а не ожидает старые ошибки.

## Границы проверки

Реальные публикации и решения по кандидатам для тестирования не выполнялись. Текущая база не скачивалась. Резервные копии остаются на Railway согласно указанию владельца; независимого внешнего архива по-прежнему нет. Проверка контраста, клавиатуры и локализации не является полной сертификацией WCAG или лингвистической экспертизой. Экономия времени менеджера в рабочем потоке пока не измерена.
