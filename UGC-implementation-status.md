# Состояние приложения · 27 октября 2026

Рабочая цепочка: Threads → анкета → предварительный отбор → Telegram → выбор менеджера → ручная передача товара. Логистика, адреса, треки и приёмка контента отсутствуют.

## Единый кабинет

Вход — [@sneg_ugc_bot](https://t.me/sneg_ugc_bot). Единственная активная база — установленная локальная SQLite. В ней сохранены SN-0001 (выбрана) и SN-0002 (новая, ИИ предлагает уточнение). Поиск SN 0002 проверен через рабочий API. Очередь при открытии показывает все новые заявки, рекомендации служат дополнительным фильтром.

Старая копия Fly выведена из работы: приложение там только перенаправляет страницы на основной кабинет. База не открывается, worker не запускается, старые API и POST отклоняются с 409. Секреты бота и подключений удалены из окружения Fly. До переключения сделаны согласованные резервные копии обеих баз; уникальных заявок в копии Fly не было. Перезапись основной базы не выполнялась.

Кнопки Telegram и прежнее сообщение с адресом Fly обновлены. SN-0002 доступна по отдельной кнопке. Webhook ведёт на основной кабинет, ожидающих обновлений нет. Telegram подтвердил отдельное уведомление о новой заявке.

## Интерфейс и обработка

Убраны пометки «пилот» из рабочего интерфейса, сообщений запуска и инструкции менеджеру. Технические имена прежних файлов сохранены для совместимости. Подключённый аккаунт Threads сохраняет своё действительное имя @ugc_pilot_lab_2026: это аккаунт, созданный владельцем; аккаунт бренда сам не подменяется.

Менеджер получает первое уведомление о новых заявках сразу, затем не чаще раза в 15 минут. Подборка редактируется в одном сообщении. Все анкеты видны сразу после сохранения независимо от готовности ИИ. Вопрос, ответ и версии кнопок обновляются в одной карточке. Решение остаётся за менеджером.

## Размещение

Бесплатный запуск работает на компьютере владельца; компьютер и окно UGC-start.cmd должны оставаться включёнными. Microsoft Dev Tunnels предоставляет временный HTTPS. При смене адреса нужно обновить callback Meta и CANONICAL_URL старого адреса Fly. Free Trial Fly останавливает машину через 5 минут и не обеспечивает 24/7. Платёжный метод не подключался.

Для постоянного размещения нужен выбор владельца. При переносе нужно остановить приём на прежнем сервере, сделать финальную согласованную копию, проверить новый сервер и только затем переключить webhook. Две самостоятельные рабочие копии базы запускать нельзя.

Перед набором остаётся проверить профиль бренда, бриф, оператора и условия в настройках. Эти данные не выдумывались. Старые ответы Google-формы не импортированы.

## Обновление интерфейса и входа

Название в интерфейсе и меню бота — SNEG. Убраны география из шапки, рекламные заголовки, объяснение воронки сбоку и повторяющиеся подписи. Очередь стала компактнее; на телефоне решения закреплены внизу карточки. Данные текущего аккаунта доступны по нажатию на аватар.

Исправлено использование общей cookie при открытии из другого Telegram-аккаунта: новый запуск всегда проверяет подписанный вход, а запросы вкладки используют собственную серверную сессию. Проверены оба направления смены аккаунтов, отказ поддельной/истёкшей сессии и отсутствие чужих анкет. В рабочем сервере подтверждены роль владельца, вход по сессии вкладки при чужой cookie, отказ неверной сессии и доступность SN-0002.

Перенос Fly отложен владельцем; база остаётся локальной. Владелец планирует размещение Railway отдельно. Ключи в Fly повторно не передавались, webhook не переключался.
