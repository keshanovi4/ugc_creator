# Запустить приложение

Двойной клик: **UGC-start.cmd**.

После сообщения «Приложение запущено» открыть [@sneg_ugc_bot](https://t.me/sneg_ugc_bot) и отправить /start. Окно и компьютер должны оставаться включёнными. Остановка — Ctrl+C.

Если требуется вход Microsoft Dev Tunnels через GitHub, выполните показанную инструкцию. Пароль вводится только на GitHub.

Если порт занят, не запускайте второй экземпляр: остановите прежнее окно. Если после аварийной остановки остался sneg-ugc/data/pilot.lock, сначала убедитесь, что прежний процесс остановлен и порт 3100 свободен, затем удалите только этот lock-файл.

Туннель временный. При изменении его адреса обновите OAuth callback в Meta и CANONICAL_URL перенаправления Fly. Рабочие кнопки Telegram обновляются при запуске. Не закрывайте и не заменяйте файл работающей базы.

Подключения описаны в [настройке владельца](sneg-ugc/OWNER-CHECKLIST.md). Независимый локальный просмотр на порту 3000 содержит вымышленные анкеты и не является рабочей базой.
